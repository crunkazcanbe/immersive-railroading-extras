# Compile-only jars (not included)

These mods are needed on the compile classpath but are **not redistributed here** — get
them from their own authors and drop them into this folder with these exact names:

| File | What it is | Where |
|---|---|---|
| `ImmersiveRailroading-dev.jar` | Immersive Railroading 1.12.2 (deobf / dev jar) | TeamOpenIndustry — build from source or their maven |
| `UniversalModCore-1.12.2-forge-1.3.2-a6546e1.jar` | UniversalModCore 1.3.2 (IR's framework; 1.3.1+ required) | TeamOpenIndustry maven |
| `LandOfSignals-1.12.2-forge-1.4.1.jar` | Land of Signals (optional integration) | CurseForge |
| `Dynmap-3.2.1-forge-1.12.2.jar` | Dynmap (optional map layer) | CurseForge |
| `OpenComputers-1.8.9a-api.jar` | OpenComputers 1.8.9 (only the `li.cil.oc.api` interfaces are used) | CurseForge / GitHub |
| `Traincraft-4.4.1-1.12.2-dev.jar` | Traincraft 1.12.2 port (legacy map integration) | — |

Railcraft is pulled automatically through CurseMaven.
